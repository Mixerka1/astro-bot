# Astro Bot — каркас

## Запуск

1. Получи токен бота у @BotFather в Telegram.
2. Вставь токен в `bot.py` в переменную `BOT_TOKEN`.
3. Установи зависимости:
   ```
   pip install -r requirements.txt
   ```
4. Запусти:
   ```
   python bot.py
   ```

## Что уже работает

- `/start` — главное меню.
- Прогноз дня по имени/нику — детерминированный результат
  (один и тот же ввод в течение дня даёт один и тот же прогноз, это нормально
  и ожидаемо: делает бота "правдоподобнее").
- Совместимость по двум именам — короткий бесплатный результат +
  кнопка на "полный расклад".

## Что нужно доделать перед запуском в прод

### 1. Реклама (основной источник заработка)
Кнопка "Смотреть рекламу и открыть полный расклад" сейчас — заглушка,
она сразу открывает результат. Нужно подключить одно из:

- **Adsgram** (специально заточен под Telegram-ботов и mini-apps,
  есть rewarded-формат "посмотрел — получил доступ").
- **Onclickads** — аналогичная модель.

Оба варианта обычно подключаются через мини-приложение (Telegram WebApp),
которое открывается по кнопке, показывает рекламу и через JS callback
сообщает боту, что показ завершён — после этого бот отправляет полный
результат.

### 2. Telegram Stars (встроенная монетизация)
Для приёма Stars используется `bot.send_invoice(..., currency="XTR", ...)`
и обработка `pre_checkout_query` + `successful_payment`. Это отдельная
платёжная механика, не привязанная к внешней рекламе — не нужны никакие
согласования, работает "из коробки" в любой стране, где доступен Telegram.

### 3. Партнёрские ссылки
В `generate_full_compatibility` или в отдельном сообщении после результата
можно добавить блок вида "хочешь подробную натальную карту у эксперта" со
ссылкой на партнёрский сервис (оплата за переход/подписку).

### 4. Виральность
Добавь кнопку "Поделиться результатом" (deep link вида
`https://t.me/your_bot?start=ref_<user_id>`), чтобы отслеживать, кто
кого привёл, и показывать реферальную статистику — это разгоняет
органический трафик без бюджета на рекламу.

## Структура кода

- `generate_daily_forecast` / `generate_compatibility` — детерминированная
  генерация на основе хэша (одинаковый ввод = одинаковый результат,
  без внешних API и затрат).
- `unlock_full_kb` — точка входа для рекламной/платной интеграции.
- FSM (`Form`) — используется для последовательного сбора имени/ника.
